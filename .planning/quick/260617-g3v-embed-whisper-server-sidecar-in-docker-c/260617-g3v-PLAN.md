<objective>
Embed whisper.cpp `whisper-server` in the SAME Docker image as the Bun proxy ("Opción A": single image, two processes) so transcription works on EasyPanel deploy without a manual daemon.

Purpose: Today the Bun proxy is an HTTP client to a whisper-server at WHISPER_HOST:WHISPER_PORT (whisper-service.ts:51 → POST /inference). On EasyPanel there is no such server, so transcription is unavailable (Noop → 503). A container entrypoint that launches whisper-server alongside the Bun app fixes this without the Bun code managing the sidecar lifecycle (Phase 6 rule).

Output: A multi-stage Dockerfile (builder compiles whisper-server, final stage runs Bun + sidecar) and a `start.sh` entrypoint.
</objective>

  <files>Dockerfile</files>
  <action>
    Replace the current single-stage Dockerfile with a two-stage build.

    BUILDER STAGE (named `builder`): Use a Debian-based image with a C/C++ toolchain (e.g.
    `debian:bookworm-slim`). `apt-get update` and install `build-essential`, `cmake`, `git`, and
    `ca-certificates` (needed for git clone over HTTPS), then `rm -rf /var/lib/apt/lists/*`. Clone
    whisper.cpp pinned to tag `v1.7.6` for reproducibility (shallow: `git clone --depth 1 --branch v1.7.6
    https://github.com/ggml-org/whisper.cpp`). Build the server with cmake:
    `cmake -B build -DWHISPER_BUILD_TESTS=OFF` then `cmake --build build --target whisper-server -j --config Release`.
    DO NOT pass `-DWHISPER_BUILD_SERVER` (that flag does not exist — the server example is built by
    default via WHISPER_BUILD_EXAMPLES=ON). The compiled binary lands at `build/bin/whisper-server`.

    FINAL STAGE: `FROM oven/bun:1.1.29` (keep this exact base — locked). `WORKDIR /app`. Install the
    runtime OpenMP dependency: `apt-get update && apt-get install -y --no-install-recommends libgomp1 &&
    rm -rf /var/lib/apt/lists/*` (libstdc++ is already present in the base; only libgomp1 is missing).
    `COPY --from=builder /<whisper.cpp clone path>/build/bin/whisper-server /usr/local/bin/whisper-server`
    so the sidecar is on PATH. Then preserve the existing Bun app build steps in order:
    `COPY package.json bun.lock ./`, `RUN bun install --frozen-lockfile`, `COPY . .` (this brings in
    index.ts, whisper-models/, start.sh, etc.). Make the entrypoint executable: `RUN chmod +x start.sh`.

    ENV: keep `ENV NODE_ENV=production` and `ENV PORT=3001` (preserve existing port). ADD
    `ENV WHISPER_HOST=127.0.0.1` and `ENV WHISPER_PORT=8080` (matches config.ts defaults and start.sh
    bind). Do NOT set `WHISPER_MODEL_ALIAS` — that is runtime/EasyPanel config and toggles HttpWhisperService.
    Keep `EXPOSE 3001`. Replace the CMD with `CMD ["./start.sh"]`.

    Do NOT add a separate `COPY whisper-models/` line — the model files arrive via `COPY . .`.
  </action>
