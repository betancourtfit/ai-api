<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| downstream client -> proxy | Untrusted Bearer token + JSON body cross here; must be authenticated and validated before any upstream call |
| proxy -> Cerebras upstream | Server-side CEREBRAS_API_KEY injected by SDK; never derived from or exposed to downstream |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | Downstream auth (index.ts) | mitigate | Require `Authorization: Bearer`; compare with `timingSafeEqual` + length pre-check (AUTH-01, AUTH-03); 401 on missing/invalid |
| T-01-02 | Information Disclosure | Upstream key handling | mitigate | CEREBRAS_API_KEY read only in config.ts and passed to SDK constructor; never in any Response body; openaiError messages are proxy-generated only |
| T-01-03 | Information Disclosure | Cerebras response normalization | mitigate | Build ChatCompletionResult field-by-field; `time_info` and `message.reasoning` structurally excluded (never spread response) — spec §12/§15 |
| T-01-04 | Tampering | Request body fields (request-schema.ts) | mitigate | `z.strictObject()` rejects non-allowlisted keys before any upstream call (VALID basis; full reject-list hardened in Plan 02) |
| T-01-05 | Information Disclosure | Logging (index.ts) | mitigate | No `console.log` of Authorization header, API keys, or message content; only non-secret status logging |
| T-01-SC | Tampering | npm installs (groq-sdk@^1.2.1) | accept | All Phase 1 packages slopcheck [OK] / Approved in RESEARCH.md Package Legitimacy Audit; groq-sdk is established (github.com/groq/groq-typescript), only a version bump of an already-present dependency — no new [ASSUMED]/[SUS] package introduced |
</threat_model>
