    ```
    AUDIO_MAX_FILE_BYTES=100
    ```

    `WHISPER_MODEL_ALIAS=whisper-1` is the alias string that `config.whisperModelAlias` will equal at test time. TEST2-06 and TEST2-07 send `model: 'whisper-1'` to match it. Without this line, `config.audioMaxFileBytes` defaults to 26,214,400 and the 101-byte test file passes the size check — TEST2-04 returns 200 instead of 413.
