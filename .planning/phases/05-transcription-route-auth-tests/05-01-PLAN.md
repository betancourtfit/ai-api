    The handler body follows this exact sequence (do not reorder — RESEARCH.md Pitfall 2):

    Step 1 — Parse multipart body with try/catch:
    Await `request.formData()`. On catch, return `withRequestId(openaiError('Failed to parse multipart form data.', 'invalid_request_error', 'invalid_request_error', null, 400))`.

    Step 2 — Build rawInput from ALL FormData entries:
    Declare `const rawInput: Record<string, unknown> = {}`. Loop `for (const [key, value] of formData.entries())` and assign `rawInput[key] = value`. This captures unknown fields (like `language`) so `z.strictObject()` in `validateAudioTranscription` can reject them (TEST2-05).

    Step 3 — Zod schema validation:
    Call `validateAudioTranscription(rawInput)`. If `!validation.success`, return `withRequestId(openaiError(validation.message, 'invalid_request_error', 'invalid_request_error', validation.param, 400))`.

    Bind: `const input = validation.data`.

    Step 4 — File size check (AUDIO-03 — 413, not 400):
    Call `validateAudioFileSize(input.file, config.audioMaxFileBytes)`. If `!sizeCheck.ok`, return `withRequestId(openaiError(sizeCheck.message, 'invalid_request_error', 'request_too_large', 'file', 413))`.

    Step 5 — Whisper alias check (AUDIO-02, post-schema):
    Evaluate `const isKnownWhisperAlias = config.whisperModelAlias !== null && input.model === config.whisperModelAlias`. If `!isKnownWhisperAlias`, return `withRequestId(openaiError("Unknown model '" + input.model + "'.", 'invalid_request_error', 'model_not_found', 'model', 400))`.

    Step 6 — Call whisperService and return (try/catch wraps the call):
    Inside try: `const result = await whisperService.transcribe(input.file, input.model)`. Then call `log('info', { event: 'transcription_complete', requestId, timestamp: new Date(requestStart).toISOString(), route: request.method + ' ' + pathname, modelAlias: input.model, fileSize: input.file.size, status: 200, latencyMs: Date.now() - requestStart })`. Return `withRequestId(new Response(JSON.stringify(result), { status: 200, headers: { 'Content-Type': 'application/json' } }))`.

    Inside catch: call `log('warn', { event: 'transcription_failed', requestId, modelAlias: input.model, fileSize: input.file.size, status: 503, latencyMs: Date.now() - requestStart })`. Return `withRequestId(openaiError('Transcription service is unavailable.', 'server_error', 'service_unavailable', null, 503))`.

    AUTH2-02 enforcement: the log calls MUST NOT include `input.file.name` or `result.text` in any field. `fileSize` is `input.file.size` (a number, not the filename). `result` is never logged.
