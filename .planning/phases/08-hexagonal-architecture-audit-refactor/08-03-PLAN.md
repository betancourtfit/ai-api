<objective>
Dissolve the 1 012-line `index.ts` god file into an **application layer** of transport-free use cases and a **thin HTTP delivery layer** of ordered routes, middleware, and presenters. Business orchestration stops returning `Response` objects; route handlers stop knowing about providers, cooldowns, and failover.

Purpose: closes the phase's two critical violations (V-01 no application layer, V-02 god file) plus V-08 (duplicated transcription flow), V-09 (duplicated provider loop), V-10 (hand-rolled cross-cutting concerns), V-11 (if-chain dispatch), and V-12 (orchestration returning HTTP). This is the plan that makes the architecture real — plan 02 only prepared the ground.
Output: 6 use-case modules, 7 route modules, 2 middleware, 3 presenters, a router, a server factory, and an `index.ts` reduced to an entrypoint. The wire contract and the test suite are untouched.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-08-03-01 | Spoofing / Elevation of Privilege | route ordering vs the Bearer gate | mitigate | `router.ts` encodes the pre-auth segment (`health`, `ready`, `gemini`) explicitly and runs `requireBearer` before the post-auth segment. A route accidentally moved into the pre-auth list would expose an authenticated endpoint; `tests/integration/server.test.ts` asserts 401 on every `/v1/*` route without a token and `gemini-compat.test.ts` asserts the Gemini-shaped 401, so both directions of the mistake fail the suite. |
| T-08-03-02 | Elevation of Privilege | constant-time key comparison moved to `middleware/bearer-auth.ts` | mitigate | `verifyToken` is moved verbatim: both buffers padded to `maxLen`, `timingSafeEqual` always executed, length equality checked only after. | T-08-03-03 | Denial of Service | body-size enforcement moved to `read-limited-body.ts` | mitigate | The byte-counted read is moved verbatim: it counts **actual buffered bytes**, ignores an understated `content-length`, cancels the reader on overflow, and returns 413. `maxRequestBodySize` on `Bun.serve` stays `Math.max(audio, chat)`. | T-08-03-05 | Information Disclosure | upstream error text reaching the client | mitigate | The terminal-error path still wraps the upstream message in `rewriteUpstreamModelIds(...)` before it reaches `openaiError`, so raw provider model IDs never leak (D-07). | T-08-03-06 | Information Disclosure | logging moved into use cases and routes | mitigate | The `Logger` port receives structured fields only. Event names and field sets are enumerated in the interfaces block and must be reproduced exactly. |
| T-08-03-07 | Tampering | SSE stream integrity | mitigate | `toSseStream` always appends `data: [DONE]`, including after a mid-stream error, so a client never hangs waiting for the sentinel (CR-03).
