SDK/Bun facts (verified in 02-RESEARCH.md from node_modules source):
- Groq: `groq.chat.completions.create({ ...params, stream: true }, { signal })` → `APIPromise<Stream<ChatCompletionChunk>>`; ChatCompletionChunk has id, choices[{index, delta{role?,content?}, finish_reason}], created, model, object:'chat.completion.chunk', x_groq?
- Cerebras: `cerebras.chat.completions.create({ ...params, stream: true } as <streaming params type>, { headers, signal })` → `APIPromise<Stream<ChatCompletion>>` where chunks are the `ChatCompletion.ChatChunkResponse` union member (has choices?, id, created, model, time_info?, usage?). Streaming params type lives at '@cerebras/cerebras_cloud_sdk/resources/chat' (same subpath as the NonStreaming type — Phase 1 deviation note).
- The APIPromise resolves when response headers arrive — 429/5xx throw at `await`, BEFORE any chunk: failover-before-stream is safe.
- Bun: `new Response(asyncGeneratorIIFE, { headers })` streams without buffering; `server.timeout(request, 0)` disables the 10s idle timeout and MUST be called before constructing the Response; `server` is the second parameter of `fetch(request, server)` (Pitfall 5: Phase 1 signature is `async fetch(request)` — must add the parameter); `request.signal` fires on client disconnect (RESEARCH Open Question 2: also acceptable if it doesn't — backpressure drains naturally; wire it anyway).
- HTTP status is committed when the Response is returned — mid-stream errors cannot become HTTP errors (inherent STREAM-04 limit).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → proxy (long-lived SSE) | Untrusted clients hold open streaming connections with idle timeout disabled |
| proxy → provider streams | Upstream SSE streams carry provider-specific fields (reasoning, time_info, x_groq) that must not reach clients |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Denial of Service | streaming connections (server.timeout 0) | mitigate | Timeout disabled per-request only, and only for authenticated stream:true requests past the Bearer gate; request.signal abort listener propagates to the SDK AbortController so downstream disconnects kill the upstream stream (no zombies) — Task 2 |
| T-02-08 | Information Disclosure | streamed chunks | mitigate | Adapters build StreamChunk field-by-field; reasoning/time_info/x_groq/usage structurally excluded; index.ts only rewrites model — Task 1 acceptance criteria |
| T-02-09 | Information Disclosure | mid-stream error handling | mitigate | Generator catch logs only an explicit structured object (event, provider, status); never err objects, headers, or payloads; upstream error bodies never relayed into the SSE stream — Task 2 |
| T-02-10 | Denial of Service | unauthenticated stream attempts | mitigate | Auth gate runs before the chat-completions handler (Phase 1, unchanged); unauthenticated requests get 401 before any upstream call or timeout change |
| T-02-11 | Tampering | replay/failover after partial output | mitigate | firstChunkSent flag + all provider selection completed before Response construction (STREAM-04); a partially-streamed response is never silently retried against another provider |
