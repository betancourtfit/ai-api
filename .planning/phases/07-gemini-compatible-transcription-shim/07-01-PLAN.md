<objective>
Add a Gemini-wire-compatible transcription route — `POST /v1beta/models/{model}:generateContent` — to `index.ts`. It accepts Google `generateContent` audio requests (`?key=` / `x-goog-api-key` auth, `contents[].parts[].inline_data` base64 body), transcribes via the existing injected `WhisperService`, and returns the Gemini `candidates[...]` success shape and `{error:{code,message,status}}` error shape. A migrating n8n Gemini transcription node should need to change only the base URL and the API key value.

Purpose: Lets existing n8n Gemini nodes migrate to this proxy by URL swap alone. The route is additive — it reuses the already-wired whisper sidecar and adds zero npm packages, leaving every `/v1/*` OpenAI endpoint untouched.
Output: Modified `index.ts` (new `geminiError()` helper + new route branch placed before the global Bearer gate) and the un-skipped Phase 7 TARGET acceptance suite in `tests/integration/gemini-compat.test.ts`.
</objective>
