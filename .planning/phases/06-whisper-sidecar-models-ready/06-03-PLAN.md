  <how-to-verify>
    1. Start a real sidecar with the native default path:
       `whisper-server --model <path-to-ggml-model>.bin --host 127.0.0.1 --port 8080 --convert`
       (If you launched it with `--inference-path /v1/audio/transcriptions`, the proxy default `/inference` will 404 → 503; either relaunch with the default path or note the override — Pitfall 3.)
    2. Confirm the sidecar is healthy: `curl http://127.0.0.1:8080/health` → expect `{"status":"ok"}` (200).
    3. Start the proxy with `WHISPER_MODEL_ALIAS` set (so `HttpWhisperService` is selected) pointing at host 127.0.0.1 / port 8080: `WHISPER_MODEL_ALIAS=whisper-1 bun index.ts`.
    4. Success path: `curl -s http://localhost:3000/v1/audio/transcriptions -H "Authorization: Bearer ${PERSONAL_PROXY_API_KEY}" -F file="@sample.wav" -F model="whisper-1"` → expect HTTP 200 and a body shaped exactly `{"text":"..."}`.
    5. Optional: `curl http://localhost:3000/ready` → expect `"whisperAvailable":true`; `curl http://localhost:3000/v1/models -H "Authorization: Bearer ${PERSONAL_PROXY_API_KEY}"` → expect the `whisper-1` alias present.
    6. Failure path: stop whisper-server, repeat step 4 → expect an OpenAI-shaped 503 `{"error":{...}}` body.
    7. Independence: with the sidecar still stopped, `curl -s http://localhost:3000/v1/chat/completions -H "Authorization: Bearer ${PERSONAL_PROXY_API_KEY}" -H 'Content-Type: application/json' -d '{"model":"<chat-alias>","messages":[{"role":"user","content":"hi"}]}'` → expect a normal chat response (not 503).
    8. Confirm `git status` / `bun.lock` show NO new npm package was added during the phase (ROADMAP criterion 4).
  </how-to-verify>
